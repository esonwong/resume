企业 AI Agent 平台

2026/04 – 至今广州丹霄信息技术有限公司平台负责人 · 主力开发

让全公司每个岗位的人，自己用 AI 解决自己的问题。

核心是子应用开放体系：业务同学不用等研发排期，自助申请 → 自动建仓发凭据 → 用 Agent 搭出自己岗位的 AI 应用并上线，市场、产品、测试、HR、法务、数据 8 个业务域都在上面建。平台向子应用开放 Agent API，让每个子应用天然具备 Agent 能力，同时业务数据经由这些应用回流汇聚，平台逐步成为企业数据与 AI 能力的汇聚点。配套技能广场沉淀可复用技能、一键装进 Claude Code / Codex，让好用法在部门间流动；AI 同事与定时任务让 Agent 常驻业务岗位、按计划自动干活。

底座：LangGraph / DeepAgents 编排、RAG 企业知识库、MCP 工具体系（Streamable HTTP MCP Server + PAT）；以 SSO / OAuth、RBAC、多租户隔离与技能审核，让"人人可建"同时可管、可审计。
